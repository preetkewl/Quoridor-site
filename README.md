# Quoridor Website

This repository hosts the official GitHub Pages website for **Quoridor**, an online multiplayer strategy board game available on Android.

## Contents

* Landing page
* `app-ads.txt` for Google AdMob verification
* Privacy Policy
* Terms & Conditions
* Support information

## Android App

Quoridor is a modern implementation of the classic strategy board game where players race to reach the opposite side of the board while strategically placing walls to block their opponents.
